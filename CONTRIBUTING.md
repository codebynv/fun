# Contributing

Thanks for contributing to this repository.

## Workflow

1. Create a focused branch from `main`.
2. Make a small, purposeful change.
3. Verify the change locally.
4. Open a pull request with a clear description.
5. Address review feedback before merging.

## Commit messages

Use concise messages that explain the change, for example:

```text
docs: clarify repository workflow
fix: correct issue template wording
```

Keep unrelated changes out of the same pull request.
