# Pull Request Checklist

Before opening a pull request in the sandbox:

- [ ] The change has a clear purpose.
- [ ] The diff contains only related files.
- [ ] Markdown renders correctly.
- [ ] No secrets or personal data were added.
- [ ] The title describes the change.
- [ ] The body explains what changed.

Small, understandable pull requests make this repository more useful as a GitHub practice sandbox.
