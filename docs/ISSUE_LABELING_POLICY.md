# Issue Labeling Policy

Use labels to make work easier to understand and triage.

- Apply labels only when they communicate useful information.
- Keep definitions short and non-overlapping.
- Use a beginner label only when the issue has enough context to start.
- Revisit labels when scope changes.
- Avoid adding labels solely to decorate an issue or manipulate repository activity.

When the repository's label set changes, keep this policy aligned with the actual labels.
